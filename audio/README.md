# Sistema de Áudio

O sistema de áudio será responsável por fornecer ao usuário as
informações correspondentes ao elemento químico selecionado.

Após a identificação da tecla pelo ESP32, o sistema deverá
reproduzir informações como:

- Nome do elemento;
- Símbolo químico;
- Número atômico;
- Massa molar;
- Família ou grupo;
- Classificação;
- Principais aplicações.

A implementação do sistema de áudio será definida durante o
desenvolvimento do protótipo físico.

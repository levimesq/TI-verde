# Componentes do Projeto

Esta página registra os principais componentes utilizados ou
previstos para o desenvolvimento da Tabela Periódica Acessível.

## Componentes disponíveis

### 1. ESP32
**Quantidade:** 1 unidade

Será utilizado como controlador principal do sistema, responsável
por receber a identificação das teclas e realizar a comunicação
com os demais componentes.

### 2. Teclados reutilizados
**Quantidade:** 2 unidades

Serão utilizados dois teclados reutilizados para representar os
elementos da Tabela Periódica.

O primeiro teclado será utilizado inicialmente nos testes com o
ESP32. Após a validação do funcionamento, o segundo teclado será
integrado ao sistema.

### 3. Cabos
**Quantidade:** A confirmar

Serão utilizados para realizar as conexões necessárias entre o
ESP32 e os componentes do protótipo.

### 4. Fios e Jumpers
**Quantidade:** A confirmar

Serão utilizados nas conexões e testes do circuito eletrônico.

### 5. Sistema de áudio
**Quantidade:** A definir

Será responsável pela reprodução das informações correspondentes
ao elemento químico selecionado.

### 6. Alto-falante
**Quantidade:** A confirmar

Será utilizado para reproduzir as informações em áudio para o
usuário.

### 7. Outros componentes eletrônicos
**Quantidade:** A confirmar

Outros componentes poderão ser adicionados conforme as
necessidades identificadas durante o desenvolvimento e os testes
do protótipo.

---

## Observações

A lista de componentes será atualizada durante o desenvolvimento
do projeto, conforme os componentes forem identificados,
testados e efetivamente utilizados no protótipo.

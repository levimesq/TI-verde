# Tabela Periódica Acessível

## Tecnologia Assistiva e TI Verde

Projeto desenvolvido para a criação de uma Tabela Periódica
interativa e acessível, voltada principalmente para pessoas com
deficiência visual.

A proposta combina identificação tátil por meio do Braille com
informações sonoras sobre os elementos químicos.

---

## Sobre o projeto

O projeto consiste na adaptação de teclados de computador
reutilizados para a construção de uma interface física capaz de
representar os elementos da Tabela Periódica.

Cada elemento será associado a uma tecla identificada em Braille.

Ao tocar ou pressionar uma tecla, o sistema deverá identificar
o elemento correspondente e fornecer informações por áudio.

---

## Objetivo

Desenvolver uma ferramenta educacional acessível que auxilie no
ensino e na aprendizagem de Química por pessoas com deficiência
visual, utilizando recursos táteis e sonoros.

---

## Informações dos elementos

O sistema deverá apresentar informações como:

- Nome do elemento;
- Símbolo químico;
- Número atômico;
- Massa molar;
- Família ou grupo;
- Classificação;
- Principais aplicações;
- Outras informações relevantes.

---

## Funcionamento previsto

O fluxo geral do sistema será:

Usuário
↓
Tecla identificada em Braille
↓
Matriz do teclado
↓
ESP32
↓
Sistema de reprodução de áudio
↓
Alto-falante
↓
Informações sobre o elemento

---

## TI Verde

O projeto utiliza teclados de computador reutilizados como parte
da estrutura do protótipo, buscando dar uma nova finalidade a
materiais que poderiam ser descartados.

A proposta relaciona Tecnologia Assistiva, educação e princípios
de TI Verde.

---

## Desenvolvimento

O desenvolvimento será realizado de forma progressiva.

Inicialmente será validado o funcionamento de um teclado com um
ESP32, tendo como primeira meta o reconhecimento correto de pelo
menos três teclas.

Após a validação do primeiro teclado, será realizada a integração
de um segundo teclado para ampliar a quantidade de elementos
representados.
